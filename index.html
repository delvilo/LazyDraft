Keyboard Shortcuts

        

        

          

            

              ctrl / ⌘command + s
              Save notes as plain text
            

            

              alt / ⌥option + c
              Copy notes to system clipboard
            

            

              ctrl / ⌘command + b
              切換嘸蝦米輸入法開關
            

            

              ctrl + alt / ⌃ control + ⌥ option
              嘸蝦米中英切換：編輯器有焦點時，純兩鍵組合放開切換
            

            

              ctrl / ⌘command + m
              切換語音轉文字錄音開關
            

            

              ctrl / ⌘command + ,
              Preferences
            

            

              ctrl / ⌘command + k
              Open list of Keyboard Shortcuts
            

            

              alt / ⌥option + f
              Toggle focus mode
            

            

              ctrl / ⌘command + shift + delete
              Delete notes
